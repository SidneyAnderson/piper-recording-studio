1 Export Dataset

Convert your generated audio to LJSpeech format for training.

python3 -m export_dataset --audio-glob '*.wav' output/{{ language }}/ dataset_{{ language }}/

This trims silence and creates a metadata.csv with audio-text pairs.

2 Set Up Training Environment

Clone Piper and install the training dependencies.

sudo apt-get install espeak-ng

git clone https://github.com/rhasspy/piper.git
cd piper/src/python

python3 -m venv .venv
source .venv/bin/activate
pip3 install --upgrade pip wheel setuptools
pip3 install -e .
bash build_monotonic_align.sh
Or use the setup script: 
bash train/setup_training.sh
This automates steps 2-4 in one command.
3 Download Pre-Trained Checkpoint

Fine-tuning from an existing checkpoint produces much better results than training from scratch, especially with fewer than 5,000 samples.

Why fine-tune? With {{ num_samples }} samples, training from scratch would need 10x more data. Fine-tuning uses an existing model's knowledge of speech patterns and only adapts the voice characteristics to match your dataset.
Recommended checkpoint for English:
mkdir -p checkpoints

wget -O checkpoints/en_US-lessac-medium.ckpt \
  "https://huggingface.co/datasets/rhasspy/piper-checkpoints/resolve/main/en/en_US/lessac/medium/epoch%3D2164-step%3D1355540.ckpt"

~400 MB download. Browse all checkpoints at huggingface.co/datasets/rhasspy/piper-checkpoints

4 Preprocess Dataset

Convert your audio and text into training-ready tensors.

cd piper/src/python
source .venv/bin/activate

python3 -m piper_train.preprocess \
  --language en \
  --input-dir {{ dataset_dir }} \
  --output-dir {{ training_dir }} \
  --dataset-format ljspeech \
  --single-speaker \
  --sample-rate 22050
5 Train

Fine-tune the checkpoint with your dataset. Requires an NVIDIA GPU.

python3 -m piper_train \
  --dataset-dir {{ training_dir }} \
  --accelerator gpu \
  --devices 1 \
  --batch-size {{ batch_size }} \
  --validation-split 0.0 \
  --num-test-examples 0 \
  --max_epochs 1000 \
  --resume_from_checkpoint checkpoints/en_US-lessac-medium.ckpt \
  --checkpoint-epochs 1 \
  --precision 32

Monitor training: Run tensorboard --logdir training/lightning_logs and visit http://localhost:6006. Watch loss_disc_all — stop when it plateaus (usually 500-1000 epochs).
Disk space: Each checkpoint is ~400 MB. With --checkpoint-epochs 1 and 1000 epochs, that's ~400 GB. Use --checkpoint-epochs 10 to save every 10 epochs, or delete old checkpoints periodically.
6 Export to ONNX

Convert your trained checkpoint to a portable .onnx model.

python3 -m piper_train.export_onnx \
  {{ training_dir }}/lightning_logs/version_0/checkpoints/YOUR_BEST.ckpt \
  my_voice.onnx

# IMPORTANT: copy the config file alongside the model
cp {{ training_dir }}/config.json my_voice.onnx.json
Both files are required: The .onnx model will not work without its .onnx.json config file. Always keep them together.
7 Test Your Voice
pip install piper-tts

echo "Hello, this is my custom trained voice!" | \
  piper -m my_voice.onnx --output_file test.wav

# Play it
aplay test.wav

You can test checkpoints during training without stopping — just export whichever checkpoint you want to try.

Tips
  • Don't over-train. More epochs is not always better. Over-fitting causes distorted, robotic output. Monitor TensorBoard.
  • Test checkpoints periodically. Export and listen every ~100 epochs to find the sweet spot.
  • Your data quality matters most. Clean, consistent ElevenLabs audio is ideal for training.
  • Sample rate must match. Your audio, preprocessing, and checkpoint must all use the same sample rate.
  • Cloud GPU option: If you don't have a local GPU, services like Google Colab (free tier), Vast.ai, or RunPod offer GPU rental by the hour.
